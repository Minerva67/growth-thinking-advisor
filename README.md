# 增长思维判断顾问 · growth-thinking-advisor

> 把梁宁《增长思维30讲》炼成一个能**帮你做判断**的 Claude Skill——不是复述课程，而是把它的框架套到你眼前这件事上，给出可执行的结论。并且，框架已经**按 AI 时代内化**：默认用 AI 原生的方式理解每个模型，而不是在结尾贴一句"AI 时代注意"。

## 这是什么

一个 [Claude Skill](https://www.anthropic.com/news/skills)。你抛一个真实处境——「这是不是机会」「该不该做」「为什么增长卡住」「要不要转型 / 烧钱 / 扩张」「模式选哪种」「该进还是该退」——它会像顾问一样给你一个结构化判断，而不是一堆道理。

## 它怎么判断（五步法）

1. **澄清决策** —— 把模糊的困惑逼成一个明确的「决定」，关键信息缺就先反问。
2. **定位（开地图）** —— 你是草莽 / 腰部 / 头部 / 顶级？这一仗多大？卡在机会·模式·组织·借势哪一关？
3. **发散（做无比现实的人）** —— 把限制性条件、用户真实处境、周期与利益相关人补够，专治 ego / 幻想 / 直觉。
4. **收敛（调框架）** —— 按问题类型取 1–3 个框架逐条落到你的具体情况。
5. **下判断（决而能行）** —— 结论 + 依据 + 下一步 + 风险兜底，敢下结论、标明假设。

**AI 时代已内化进框架本身**，三个默认镜头贯穿始终：
- 信息优先 = 会用模型 + 私有数据 / 数据飞轮；
- 限制条件里默认含「AI 松绑了什么」（爆发来自空白，AI 正批量制造空白）；
- 分发默认含 SEO / GEO / 被模型选中，护城河默认看数据飞轮与交付纵深。
- 同时守住一条边界：**AI 不改人性与周期**——组织、关系、借势、进退照原样用。

## 安装

**在 Claude Code 里用**：把 `growth-thinking-advisor/` 整个文件夹放到 `~/.claude/skills/` 下，重开一个会话即可自动加载。之后直接说「帮我判断一下要不要做 X」，或 `/growth-thinking-advisor`。

**在 Claude 网页 / App（chat）里用**：把本仓库打包成 zip，到 claude.ai 的 **Settings → Capabilities → Skills → Upload skill** 上传（自定义 skill 上传一般需 Pro / Max，团队版需管理员开启）。

## 用法示例

> 我想做一个帮小商家自动做归因诊断的工具，这是不是一个好机会？

它会给你：决策重述 → 玩家定位 → 该补的信息 → 判断 → 依据（破局点三特性 / 爆品公式软件版 / 分发是否已转 SEO·GEO…）→ 下一步 → 风险兜底。
